🛡️ Bezpečnostní upozornění (macOS + Apple Silicon)

SiliconMonitor 0.9.1 (Founder Edition) je předběžná verze aplikace pro macOS 13.0 a novější, určená výhradně pro zařízení s Apple Silicon (M1, M2, M3).

Aplikace je distribuována jako archiv:
📦 SiliconMonitor.zip
Stačí jej rozbalit a přetáhnout SiliconMonitor.app do složky Aplikace.

⚠️ Varování při prvním spuštění
macOS může při prvním spuštění zobrazit varování jako:

„Tuto aplikaci nelze ověřit…“
Apple nemohl potvrdit, zda tato aplikace obsahuje škodlivý kód.
Toto se objevuje, protože aplikace není zatím podepsaná vývojářským certifikátem.
Pre-release verze je určena hlavně pro komunitní testování a získávání fanoušků.

✅ Aplikace je bezpečná a její zdrojový kód bude otevřený k nahlédnutí.
✅ V budoucí verzi 1.0.0 bude aplikace podepsaná a notarizovaná Applem, a varování už se neobjeví.

🧩 Jak aplikaci spustit
Stáhni SiliconMonitor.zip a rozbal jej
Přetáhni SiliconMonitor.app do složky Aplikace
Klikni pravým tlačítkem → Otevřít
V dialogu klikni Otevřít
macOS si volbu zapamatuje a příště aplikaci otevře bez varování.
